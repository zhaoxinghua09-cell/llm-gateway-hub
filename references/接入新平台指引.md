# 接入新平台指引（LLM Gateway Hub）

> 目标：任何提供 **OpenAI 兼容 /chat/completions** 接口的大模型平台，都能在 5 分钟内接入。
> 当前主流平台（豆包/千问/DeepSeek/Kimi/智谱/混元/硅基流动/本地 Ollama）均已兼容。

## 一、判断平台能否接入（3 个条件）

1. 提供 HTTP API，支持 `POST /chat/completions`（OpenAI 兼容格式）
2. 鉴权方式：`Authorization: Bearer <API Key>`
3. 请求体：`{"model": "...", "messages": [...], "max_tokens": ...}`

> 满足即接入；不满足（如自定义协议）需写一个适配函数（见第三节）。

## 二、接入步骤（配置加一段）

在 `gateway_config.json` 的 `providers` 增加一个条目：

```json
"新平台名": {
  "enabled": true,
  "base_url": "https://平台API地址/v1",
  "api_key": "你的Key",
  "default_text_model": "模型ID",
  "default_image_model": "",            // 无图像能力留空
  "price_text_in": 0.5,                 // 输入价格（元/百万token）
  "price_text_out": 2.0,                // 输出价格（元/百万token）
  "price_image_per": 0.2                // 图像价格（元/张）
}
```

调用：`python ai_gateway.py text --provider 新平台名 --prompt "你好"`

## 三、特殊情况：非 OpenAI 兼容平台

极少数平台协议不同（如部分自研接口），需要写适配函数：
在 `ai_gateway.py` 中新增 `call_text_xxx()`，把平台响应**转换为统一格式**返回
`(content, usage_dict, model, kind)`，即可复用预算/台账/日志能力。

## 四、接入前必查（较真清单）

- [ ] 价格与零成本额度（官网实时口径，别信二手信息）
- [ ] 模型 ID 是否带版本后缀（如火山方舟 `-260628`）
- [ ] 是否需要创建"推理接入点/Endpoint"（部分平台旧版需要）
- [ ] 个人/企业实名要求（大部分平台要求实名才能建 Key）
- [ ] Key 只显示一次 → 立即保存（老规矩）
- [ ] 该平台是否在你组织允许的合规范围

## 五、安全提醒（接入任何平台都一样）

1. Key 只进本机私有配置，不进云/代码仓库/群聊
2. 配置权限收紧（icacls /inheritance:r /grant:r "用户:(R)"）
3. 轮换纪律：机器异常立即重建 Key
4. 预算先设小额试跑，确认计价无误再放量
