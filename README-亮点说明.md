## 九大核心亮点

### 🔐 1. 安全保密性（Key 不裸奔）
- 所有 API Key **只存本机私有配置**，绝不进云文档/网盘/群聊/代码仓库
- 配置 ACL 权限锁（仅本机用户可读），命令用变量读 Key 不落盘
- 传输全程 TLS 加密；**泄露即轮换**纪律兜底
- 发布包内**零真实密钥**（全占位符），可放心分发

### 🛡️ 2. 运行保障机制（不失控、不丢账）
- **预算硬拦截**：月度预算 80% 预警 / 100% 拒调——花多少钱你说了算
- **自动消耗台账**：每笔调用自动记账（时间/模型/tokens/费用/累计），全程可查
- **三级通路冗余**：主 API / 备通道 / 兜底链路，单点故障不瘫痪
- **自动备份**：团队数据每日备份，保留 7 份滚动

### 🏠🏢 3. 两地接入（家里 + 公司）
- 中枢在本机，**公司电脑通过云同步实时读取**（微云/文件同步）
- 两地双端协同，人在哪都能指挥团队、查看台账
- 双端交接单 + 操作指引，20 分钟完成接入

### 🤖 4. 本地模型（离线也能干）
- 内置 **Ollama 本地模型**接入位（零成本、离线、断网可用）
- 断网时自动降级到本地模型，**团队不因网络瘫痪而停摆**

### 💰 5. 省积分（每一分都花在刀刃上）
- **零成本额度优先**：各平台新户零成本额度（50万token/200张图/100万token）先用完再花钱
- **便宜模型兜底**：文本默认 Turbo/Lite 档，复杂任务才上高端模型
- **预算管控**：硬拦截防止失控，异常消耗自动标红
- **记账透明**：每笔消耗可查，没有糊涂账
- 实测：封面图 0.2 元/张，日常文本约 0.01 元/次——**近乎零成本运行**

### 🎛️ 6. 好管控（一个入口管所有）
- 统一命令行入口：`text / image / models / budget` 四个命令搞定一切
- 统一预算、统一台账、统一 Key 管理——**不散、不乱、不重**

### 📊 7. 可视化（账目一眼清）
- 预算状态一键查询（`budget` 命令，剩余/占比/预警状态）
- 消耗台账结构化记录，**周报/月报随时可汇总**
- 团队全景图：架构/机制/资产/通路/状态一图览

### 🎯 8. 统一指挥（一个中枢，多家大脑）
- **一个 Agent（你/你的 AI）自由调用所有平台**，不用切换环境
- 构建"AI 团队"：一个指挥中枢 + 多个专业执行（生成/办公/分析），各司其职
- 任务按类型自动路由到最合适的模型——**人类只拍板，干活全自动**

### 🧬 9. 多模态（文本/图像/视频/语音通吃）
- 文本对话、图像生成、视频生成、语音/向量模型——各平台能力全接入
- **各家发挥各自优势**：
  | 任务 | 精选平台 | 理由 |
  |------|----------|------|
  | 图片/视频生成 | 豆包 | 生成能力强 |
  | 办公文档/表格 | 千问 | 办公生态 |
  | 高性价比文本 | DeepSeek | 极便宜 |
  | 超长文档 | Kimi | 200万字上下文 |
  | 离线/断网 | Ollama 本地 | 零成本离线 |
  | 中文/工具调用 | 智谱 GLM | 老牌稳健 |

**省的不是一块两块，是长期可持续的低成本运行**——封面图 0.2 元、文本近 0 成本。

### 🔌 可扩展（最省事）
新平台接入 = **配置加一行**（base_url + Key + 模型 + 价格），网关代码零改动。

**不是"又一个 API 封装"，而是一套完整的大模型基础设施**：能指挥、能管钱、能保密、能保障、能扩展。

## 扩展位（预留设计）

本方案为**持续扩展**而设计，预留三个扩展位：

| 扩展位 | 预留内容 | 如何启用 |
|--------|----------|----------|
| **① 平台扩展位** | 任意 OpenAI 兼容平台（豆包/千问/DeepSeek/Kimi/智谱/混元/硅基流动/Ollama…） | 配置 `providers` 加一段，代码零改动 |
| **② 能力扩展位** | 文本 / 图像 / 视频 / 语音 / 向量 / 深度思考 | 各平台开放即配置即用（`default_*_model` 字段） |
| **③ 组织扩展位** | 多执行角色（生成 / 办公 / 分析 / 质检…）按组织方式分配 | 在统一入口下按任务类型路由，角色可增可减 |

> 当前已在 SynomosAI 组织运行方式下验证：一个指挥中枢 + 多个专业执行角色，按任务类型自动路由到最合适的模型，角色与资源按需分配、随时扩编。
